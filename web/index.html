SubDir Commander 38

A disk commander for a stock C64. List a drive, move through it a line or a page at a time, and run, load, rename, copy, delete or validate files, including copies from one drive to another.

Disk image subdir38.d64 Machine code %SubDirCommand38 · 20 blocks BASIC SubDirCommand.38 · 28 blocks

Run it

In VICE, attach the disk to drive 8:

x64sc -8 subdir38.d64

Then on the C64. The file names contain capital letters, so ? stands in for them:

LOAD"%*",8
RUN

for the machine code version, or

LOAD"?UB?IR?OMMAND.38",8
RUN

for the BASIC one. Add -9 other.d64 to try copying between drives.

Two versions

Machine code draws the list straight into screen memory, so moving and paging are instant. It keeps the directory in the RAM under the BASIC ROM and copies between drives through a 33 KB buffer.

BASIC is the readable one, with a 138-byte helper in the cassette buffer for drive-to-drive copies.

Loading done right

Programs are handed to BASIC the way you would type LOAD and RUN, so BASIC sets its end-of-program pointer itself. A program loaded from the commander saves at its own size.

A failed copy (disk full, write error, RUN/STOP) removes the partial file and gives its blocks back.
